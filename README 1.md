# ATLAS Lunar Rover

A Robotic Lunar Rover project developed during the ATLAS Summer Tech School 2026.

## About the Project

As part of the ATLAS Summer Tech School 2026, I worked on a hands-on Robotic Lunar Rover project combining robotics, electronics, embedded systems, Arduino programming, and engineering design.

The program progressed from basic electronics and motor control to rover assembly, sensor integration, obstacle avoidance, line following, and autonomous navigation.

## My Contribution

During the program, I worked on the design, assembly, wiring, programming, and testing of the rover.

My work included:

- Controlling DC motors
- Working with motor-driver circuitry
- Implementing motor speed control using PWM
- Working with sensors and embedded systems
- Developing rover-control code
- Testing and debugging the rover
- Working with 3D-printed rover components

## Technologies & Tools

- ESP32

- C/C++ (Arduino programming)
- DC Motors
- Motor Driver
- Sensors
- PWM
- 3D Printing
- Electronics

## Development Progression

The project developed through multiple stages:

1. Basic motor control
2. Motor speed control
3. Joystick-based control
4. Six-motor rover control
5. Advanced browser-based rover control
6. Sensor-based and autonomous rover functionality

This repository will document the project progressively rather than uploading all project material at once.
